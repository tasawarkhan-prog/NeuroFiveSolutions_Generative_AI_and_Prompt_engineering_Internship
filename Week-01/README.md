## 🎯 Task 1: Zero-Shot vs Few-Shot Prompting Showdown

### Task Description
Classify 10 customer support messages into three categories:
- **Complaint** 😤
- **Question** ❓  
- **Praise** 👍

### Results Summary

| Tool | Zero-Shot Accuracy | Few-Shot Accuracy |
|:---|:---:|:---:|
| ChatGPT | 10/10 (100%) | 10/10 (100%) |
| Claude | 10/10 (100%) | 10/10 (100%) |
| Gemini | 9/10 (90%) | 10/10 (100%) |

### Key Findings
- ✅ Few-shot prompting achieved perfect accuracy across all tools
- ✅ Zero-shot performance varied between tools
- ✅ Gemini showed the most improvement with examples

## 📝 Reflection

The few-shot approach achieved perfect accuracy across all three tools, while zero-shot performance varied and was noticeably lower. The key reason is that providing examples explicitly anchors the model's understanding of the task's boundaries, especially subtle distinctions like a frustrated statement that is still a complaint vs. a polite inquiry.
